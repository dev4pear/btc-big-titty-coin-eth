# Big Titty Coin ($BTC) — Ethereum landing page

Static single-page site for the Ethereum launch of **Big Titty Coin ($BTC)**.

## Open locally

1. Unzip the archive.
2. Open `index.html` in any modern browser  
   (double-click, or drag into Chrome / Firefox / Safari / Edge).

No build step. No server required.

Optional local preview:

```bash
cd btc-big-titty-coin-eth
python3 -m http.server 8765
# then visit http://127.0.0.1:8765
```
